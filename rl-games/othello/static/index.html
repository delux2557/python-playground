黑白棋是双人零和博弈:你多一子、对手就少一子,所以奖励只在终局给(+1 胜 / -1 负 / 0 平)。 自对弈 = 让模型和"以前的自己"下棋,互相磨炼;模型对战 = 把两个已登记模型放进同一张棋盘,用比分直接判断谁更强。
